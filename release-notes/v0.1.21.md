# Reaper 0.1.21

**UI build 504**

## Improvements

- **Windows:** Native windows show on first page load (launch splash) instead of waiting for Monaco and other late assets.
- **Import / clone:** Git import runs off the async server thread so the app stays responsive; clearer status while large repos copy.
- **Cursor agent:** Only the primary window eagerly warms Cursor sessions; extra windows warm on first chat. Concurrent session creates for the same repo are coalesced; reuse skips redundant warm calls.
- **Open project:** Initial README / build file opens in the background so the file tree appears sooner.
