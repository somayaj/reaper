# Reaper 0.1.22

**UI build 505**

## Improvements

- **Editing:** Smoother typing in all files — no gutter/toolbar/coverage flicker on every keystroke; debounced run targets and diagnostics; test-file run widgets only repaint when layout changes.
- **macOS distribution:** Bundled JDK drops `jmods` (notarization-safe); nested debug adapters and tools signed with Developer ID + hardened runtime.
- **Quality:** Edit-smoothness regression harness in `test-editor-regression.mjs`.

## Install

Download from [GitHub Releases v0.1.22](https://github.com/reaper-org/releases/releases/tag/v0.1.22).

DMGs are Developer ID signed and notarized for macOS Gatekeeper.
