# Reaper 0.1.13

**UI build 496**

## Fixes

- **Editor:** Stop tab strip and run-toolbar churn on every keystroke (fixes visible “shake” while typing).
- **Agent (Cursor):** Stream agent progress via dedicated `activity` events — thinking/tools update the status line without filling the reply bubble before text arrives.

## Install

Download the DMG for your Mac from [GitHub Releases](https://github.com/reaper-org/releases/releases/tag/v0.1.13):

- Apple Silicon: `reaper-0.1.13-macos-arm64.dmg`
- Intel: `reaper-0.1.13-macos-x86_64.dmg`
