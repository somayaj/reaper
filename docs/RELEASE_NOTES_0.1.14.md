# Reaper 0.1.14

**UI build 497**

## Fixes

- **Agent (Cursor):** Stream progress immediately — SSE keepalive + activity events right after connect (no long stuck “Waiting for reply…” while the agent starts).
- **Cursor bridge:** Refresh `~/reaper/cursor-bridge` when the app version changes and restart the bridge so updates actually load.

Download the DMG for your Mac from [GitHub Releases](https://github.com/reaper-org/releases/releases/tag/v0.1.14):

- Apple Silicon: `reaper-0.1.14-macos-arm64.dmg`
- Intel: `reaper-0.1.14-macos-x86_64.dmg`
