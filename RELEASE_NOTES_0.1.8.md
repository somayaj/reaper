Reaper 0.1.8 (build 491) — macOS arm64.

**Install:** download the **DMG** below. Ignore GitHub's automatic "Source code (zip)" and "Source code (tar.gz)" links — those archives are empty placeholders and are not distributable builds.

| Mac | Download |
|-----|----------|
| Apple Silicon (M1/M2/M3/M4) | `reaper-0.1.8-macos-arm64.dmg` |

Drag Reaper.app to Applications, then launch.

### What's new

- **Fresher Cursor agent connection:** An idle Cursor session (90s) is replaced before the next send, so a cold cloud connection does not slow the following chat. Recent messages still reuse the same session.

**Tip:** opening the .dmg repeatedly mounts a new Finder volume each time — eject old Reaper drives or run `scripts/eject-reaper-dmgs.sh`.
