            SSL / Certificates
            
          
          

            
            
            
            
            
PostgreSQL and MySQL/MariaDB. Use absolute paths to PEM files for CA, client certificate, and client private key (same idea as DBeaver). MySQL 8 uses --ssl-mode; MariaDB clients use --ssl / --ssl-ca (Reaper picks based on your client). Not used for plain Docker Compose local DB exec.

          

        

        

          
            SSH tunnel / Bastion
            
          
          

            
            
            
            
            
            
            
            
            
Opens ssh -N -L through a bastion (jump host) and connects the DB client to 127.0.0.1. Uses key file and/or ssh-agent (BatchMode). Password prompts are not supported. Combine with SSL above when the remote DB requires TLS.
